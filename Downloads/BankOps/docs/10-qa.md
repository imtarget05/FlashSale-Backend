# 10 — Test, QA, acceptance

## Test pyramid

- Unit: domain transitions, signed quantities, decimal ledger, mapping validation, permission policy.
- Integration PostgreSQL thật qua test container: transaction rollback, unique constraints, row locks, Alembic, outbox, reconciliation.
- API contract: OpenAPI snapshot, schema/error/status, pagination, object authorization, idempotency replay.
- Flutter widget/golden có chọn lọc: navigation breakpoint, banner DEMO, form errors, progress states, accessibility semantics.
- E2E: maker tạo → checker khác duyệt → movement/journal → dashboard/reconciliation; connector sandbox → staging → draft.

## Definition of Done

Lint/typecheck/test backend+Flutter pass; migration lên DB trống và từ revision trước; mọi endpoint write có auth, permission, audit, idempotency thích hợp; UI loading/error/empty; demo watermark; review bảo mật connector; API docs cập nhật; test trên Android/iOS simulator, Chrome và ít nhất một desktop target. Báo rõ target chưa được test nếu thiếu môi trường build.
