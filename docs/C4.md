# FlashSale-Backend — C4 Architecture

> Source of truth: repo README + `docs/architecture/current-architecture.md`
> + ADRs 001–005. Flow: API → Redis Lua gatekeeper → RabbitMQ → worker → PG
> truth; v2 LOCAL runs the same saga on kind/Kafka (see `docs/EVIDENCE.md` §5).

## C4-Context

```mermaid
C4Context
    title FlashSale — System Context
    Person(buyer, "Buyer", "50 concurrent buyers vs stock 10")
    Person(staff, "Staff/Admin", "ops, resync, recovery runbooks")
    System(fs, "FlashSale Platform", "zero-oversell orders: Redis gate, queue, PG truth")
    System_Ext(pay, "Payment provider", "timeout/remind/cancel webhooks")
    System_Ext(az, "Azure", "Service Bus, ACR, AKS/GitOps (prod path)")
    Rel(buyer, fs, "purchase attempts", "HTTPS")
    Rel(staff, fs, "operates", "HTTPS /internal")
    Rel(fs, pay, "settles", "API")
    Rel(fs, az, "deploys, messages", "Infra")
```

## C4-Container

```mermaid
C4Container
    title FlashSale — Containers
    Person(buyer, "Buyer", "HTTPS")
    Container_Boundary(f, "FlashSale") {
        Container(api, "Order.Api", "ASP.NET Core", "Lua gate, enqueue, idempotency")
        Container(redis, "Redis", "cache", "stock mirror + reservation ledger")
        Container(mq, "RabbitMQ/ServiceBus", "queue", "at-least-once orders buffer")
        Container(wk, "Order.Worker", ".NET", "persist, ack-after-persist, DLQ")
        ContainerDb(pg, "PostgreSQL", "SQL", "authoritative stock + orders")
    }
    Rel(buyer, api, "orders", "HTTPS")
    Rel(api, redis, "Lua CAS reserve", "TCP")
    Rel(api, mq, "publishes", "AMQP")
    Rel(mq, wk, "delivers", "AMQP")
    Rel(wk, pg, "atomic UPDATE", "SQL")
```
